# Initial API Contract

## Purpose

This document defines the initial data contract between the React frontend, FastAPI backend, and DawgDecision decision engine.

The contract is a draft for the MVP and may change after review with the Platform & Backend Engineer and Frontend Lead.

## Initial Endpoint

### Compare Two Scenarios

`POST /api/v1/comparisons`

This endpoint accepts two financial scenarios and returns deterministic comparison results generated by the decision engine.

## Request

```json
{
  "scenarios": [
    {
      "name": "Apartment A",
      "monthly_income": 1500,
      "rent": 900,
      "utilities": 100,
      "transportation": 150,
      "other_expenses": 0
    },
    {
      "name": "Apartment B",
      "monthly_income": 1500,
      "rent": 1050,
      "utilities": 80,
      "transportation": 50,
      "other_expenses": 0
    }
  ]
}
